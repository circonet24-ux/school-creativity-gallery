# معرض الإبداع المدرسي 🎨

تطبيق ويب عربي (RTL) لعرض إبداعات المعلمات والطلاب — يعمل **فورًا** بفتح `index.html` في المتصفح، بدون أي تثبيت.

مستلهم من التطبيق المرجعي (تنظيم المعرض كبطاقات وأقسام وتنقل بسيط)، بتصميم خاص: أبيض + أخضر فاتح + تركواز + لمسات ذهبية، بدون بنفسجي.

## التشغيل

1. افتحي الملف `index.html` في المتصفح (يفضل Chrome أو Edge).
2. أول تشغيل: اذهبي لـ «🔐 دخول المسؤول» وأنشئي حساب المسؤول (يُحفظ على هذا الجهاز فقط).
3. من لوحة التحكم: أضيفي الأعمال → انشريها → ستظهر للزوار فورًا.

> البيانات الافتراضية توضيحية بأسماء وصور رمزية (SVG) وقابلة للحذف من لوحة التحكم ← الإعدادات.

## المزايا المنفذة

- رئيسية: اسم المدرسة/الشعار/الترحيب قابلة للتعديل + بطاقتان كبيرتان (👩‍🏫 👨‍🎓) + أعمال مميزة + زر دخول مسؤول.
- معرضان مستقلان بفلاتر (النوع/التصنيف/الصف-التخصص) وبحث، ورسالة مناسبة عند خلو القسم.
- بطاقة عمل: غلاف، عنوان، اسم صاحب العمل حسب الخصوصية (كامل/الأول/مخفي)، الصف/التخصص، النوع/التصنيف.
- نافذة تفاصيل واسعة: معاينة (صورة/فيديو/PDF داخل الصفحة)، زر رابط خارجي، زر تنزيل حسب خيار المسؤول، تنقل سابق/تالي.
- لوحة مسؤول: إضافة/تعديل/حذف (بتأكيد)، مسودة/منشور، مميز، ترتيب، تصنيفات، إعدادات (نصوص+ألوان+خصوصية)، تغيير كلمة المرور، خروج.
- حدود رفع موضحة قبل الرفع + مؤشر تقدم + رسائل نجاح/فشل.
- متجاوب (جوال/تابلت/حاسوب) وحركات خفيفة.

## حدود النسخة الحالية (مهم)

- الحفظ **محلي على هذا المتصفح/الجهاز** (localStorage) — يبقى بعد تحديث الصفحة، لكنه **لا يظهر على أجهزة أخرى** ولا يحميه خادم حقيقي.
- صلاحيات المسؤول مطبقة داخل الواجهة فقط. **لا تعتبريها حماية خادم مكتملة.**
- للتفعيل الكامل متعدد الأجهزة راجعي `BACKEND_REQUIREMENTS.md` (ربط Supabase/Firebase أو خادم Node).

## بيانات الدخول

- لا توجد كلمة مرور ثابتة في الكود. تُنشأ عند أول تشغيل من صفحة الدخول.
